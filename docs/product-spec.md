# Snap Recorder MVP 产品规格

## 目标

用最短路径完成高质量 Mac 录屏，不进入编辑器，不要求用户设置格式或选择保存目录。

主流程：

未录人声：

`首次授权 → 选择来源 → 3 秒倒计时 → 录制 / 暂停 → 结束 → 选择画质 → 保存到下载`

录制人声：

`开启人声并授权 → 录制 → 结束 → 选择画质与一种或两种人声版本 → 保存到下载`

## 三种来源

### 浏览器窗口

- 支持 Safari、Chrome、Edge、Arc、Firefox、Brave、Orion、Opera。
- 只抓选中窗口，其他应用和其他浏览器窗口不进入成片。
- 输出跟随开始录制时的浏览器窗口比例，不拉伸、不裁切；浏览器完整铺满成片。
- 优先保留 Retina 原始像素，最高约 3840×2160。
- 不添加桌面壁纸、渐变、圆角、阴影或额外画布。

### 整个屏幕

- 录制当前主显示器。
- 保持显示器原始比例，不拉伸、不裁切。
- 优先保留显示器原始像素，最大输出约 3840×2160。
- Snap Recorder 的窗口、倒计时和控制胶囊不会进入视频。

### 局部录像

- 录制当前主显示器上的可调区域；Snap Recorder 主窗口、选区框、蒙版框、倒计时和控制胶囊均不进入成片。
- 提供 16:9、9:16、4:3、3:4、21:9、1:1 与自定义比例。
- 固定比例通过四角等比缩放；自定义比例支持边缘与四角自由缩放；选区内部可拖动位置。
- 大选区提供方角与圆角，默认圆角；圆角状态可选柔和暗角，只在四个角产生轻微渐隐。
- 固定比例可开启聚焦蒙版。蒙版框可拖动和自由缩放，框内保持原色，框外转为单色并压暗 50%。
- 聚焦蒙版提供方角与圆角，默认圆角；屏幕预览使用低对比灰色细框。
- `⌘E` 在可调整选区与点击穿透浮层之间切换；锁定后框线仍可见，下面的界面可正常操作。
- 主窗口聚焦时 `⌘R` 可开始任意模式录制；局部浮层锁定后 `⌘R` 临时全局生效。录制中与暂停时 `Esc` 全局结束录制。
- 优先保留选区原始像素，最大输出约 3840×2160。

## 全局录制选项

- “电脑声音”与“人声（麦克风）”保持独立开关；人声默认关闭。
- “录制鼠标”对浏览器、整个屏幕和局部录像三种模式同时生效，默认开启。
- 开启录制鼠标时不录入系统箭头，由成片合成器绘制圆形高亮光点与柔和光晕；左键、右键或中键点击时，从按下位置产生一次约 0.65 秒的扩散波纹。
- 关闭录制鼠标时，成片不包含光标与点击提示。
- 鼠标位置与按键状态通过公开的会话状态轮询，不新增辅助功能或输入监控权限。

## 状态与反馈

- 未授权：只显示授权说明和唯一主按钮。
- 空窗口列表：明确提示先打开浏览器，并提供刷新。
- 录制结束后提供“最高画质 / 清晰小体积”两档；最高画质保留录制原片，小体积档保持同分辨率。
- 倒计时：3、2、1，每个数字 1 秒；数字消失后等待约 120 毫秒再启动采集。
- 录制中：顶部胶囊显示红点、真实录制时长、暂停和结束。
- 暂停：红点变橙色，显示“已暂停”；继续时不再次倒计时。
- 处理中：显示“正在整理录制…”或“正在生成视频…”，不显示虚假百分比。
- 未录人声：停止后选择画质，再保存一个 MP4。
- 已录人声：停止后选择画质，并显示“完整视频”和“视频和人声分轨”两张可多选卡，默认勾选完整视频。
- 完成：显示一个、两个或三个文件名、“在访达中显示”和“再录一个”。
- 失败：保留原因，返回后可以直接重试。

## 输出

- MP4 / H.264 / SDR / Rec.709。
- 默认 60 fps 采集，实时硬件编码。
- 最高画质档按像素数使用约 24–68 Mbps。
- 清晰小体积档使用同分辨率、约 8–22.7 Mbps，并允许帧重排提升压缩效率；视频体积目标约为最高画质的 1/3。
- 实际平均码率与最终体积会随画面复杂度变化，声音轨也会占用少量空间。
- 电脑声音为 AAC 48 kHz 双声道，192 kbps。
- 人声默认关闭；开启后使用系统默认麦克风、AAC-LC 48 kHz 单声道、192 kbps。
- 合并导出为一个 MP4，音频混合为 AAC 48 kHz 双声道、256 kbps；视频轨不重新编码。
- 分开导出为 MP4（含电脑声音，如开启）与 M4A 人声，不打包；两个文件时长误差不超过 40 毫秒。
- 完整视频文件名：`Snap 录屏 YYYY-MM-DD HH.mm.ss.mp4`。
- 分轨视频文件名：`Snap 视频 YYYY-MM-DD HH.mm.ss.mp4`。
- 分轨人声文件名：`Snap 人声 YYYY-MM-DD HH.mm.ss.m4a`。
- 保存位置：`~/Downloads`。

## 不做

- 剪辑、变焦、字幕、摄像头、云分享。
- 导出格式、分辨率、精细码率和文件夹选择。
- 麦克风设备选择、多显示器选择。

## 首版验收

- 首次启动能解释权限用途，授权后可进入来源选择。
- 倒计时与工具界面均不出现在成片中。
- 局部录像的固定比例在拖动后仍保持比例，自定义比例可自由改变；选区坐标与 Retina 输出像素正确对应。
- 聚焦蒙版默认圆角，可切换方角；框外为单色并压暗 50%，蒙版预览框不进入成片。
- 局部选区按 `⌘E` 后能够点击穿透，`⌘R` 可从下层应用直接开始；录制中按全局 `Esc` 能正常进入导出流程。
- 三种模式关闭“录制鼠标”后成片不出现系统箭头、光点或点击波纹；开启后显示圆形光点，点击波纹从真实点击位置扩散。
- 浏览器成片不出现其他应用、Dock、菜单栏、桌面图标或通知。
- 暂停后继续录制，暂停空档从最终文件中移除。
- 结束后无需选择路径即可在下载目录获得 QuickTime 可播放的 MP4。
- 开启人声后，合并文件同时包含电脑声音（如开启）与人声，视频画质不下降。
- 分开导出正好得到 MP4 与 M4A 两个文件，时长对齐且不生成 ZIP。
- 同时勾选两种版本时，一次得到完整 MP4、分轨 MP4 和 M4A 共 3 个文件；任一生成步骤失败都不会删除原始素材。
- 来源关闭或编码失败时给出明确反馈，不静默丢失。
